↓ 日時確認後、そのままヒアリングへ！

① ご予算「おおよそのご予算はどのくらいをお考えですか？」

③ 購入時期「いつ頃までにとお考えですか？」

→ ヒアリング後：

↓
導入第一声・本人確認
「お忙しいところ恐れ入ります。（屋号）の○○と申します。○○様のご連絡先でよろしいでしょうか？ご本人様でいらっしゃいますか？」
✓ ご本人様
→ 挨拶へ
✗ 別の方・ご不在
携帯の場合：間違い電話・いたずらの可能性を確認
固定の場合：「お手数ですがご本人様にお代わりいただけますか？」

それでも難しい場合：
「それでは改めてご連絡させていただきます。何時頃であればご在宅でしょうか？」
→ 時間帯をメモして電話を切る
↓
導入ご挨拶・要望確認
「先ほど○○○（アットホーム・スーモ・当社HPなど）より○○（物件名）に対してお問い合わせいただきまして誠にありがとうございます。本日は○○○（要望項目を読み上げる）をご希望ということでよろしいでしょうか？」
※ フォームのチェック項目を読み上げて確認する

ルール1まず日程を決定する
「ありがとうございます！ではさっそく日程を決めましょう。」
「今週末はいかがでしょうか？午前・午後どちらがよろしいですか？」
→ 候補日を2〜3提示して確定
「当日いらっしゃる人数は何名様でしょうか？」
「後ほど担当よりご連絡させていただきますが、ご挨拶がてら改めてご来店日の確認とご案内をさせていただきます。」
↓
ルール2資料のみ希望 → 3段階フックで来店を促す
「承知しました。実はご来店いただくと3つのメリットがあります。少しだけよろしいですか？」
フック1「業者専用の「レインズ」というサイトがありまして、アットホームやSUUMOには載っていない非公開物件もご覧いただけます。ご来店いただいた方だけにご紹介できる仕組みです。」

フック2「また当社にはモデルルームがありますので、中古物件を購入してリフォームをした場合のイメージをつかんでいただけるんです。」
「いかがでしょうか？少しだけお時間いただけませんか？」
✓ 来店OK
→ 日程確定へ

→ 切り札へ

切り札即日わかるローン診断ツール
「さらに当社では早ければ当日におおよその借入可能額がわかる住宅ローン診断ツールもご利用いただけます。気に入った物件をすぐに押さえる判断ができます。」
✓ 来店OK
→ 日程確定へ

「実は業者専用の「レインズ」というサイトがありまして、SUUMOなどには載っていない非公開物件もご来店いただいた方だけにご紹介できます。また当社にはモデルルームもありますのでリフォームのイメージもつかんでいただけます。さらに早ければ当日におおよその借入可能額がわかる住宅ローン診断ツールもご利用いただけます。」
「ぜひ一度ご来店いただけませんか？」
✓ 来店OK
→ 日程確定へ
✗ やっぱり無理
→ ルール4へ
↓
ルール4来店断られた → 資料送付 → ヒアリング → 連絡先確認
「承知しました。それでは資料をお送りさせていただきます。メールと郵送どちらがよろしいでしょうか？」
→ 送付先を確認してメモ
「よろしければ、簡単にご条件だけお聞きしてもよろしいでしょうか？担当がお客様に合った情報をご用意してご連絡いたします。」
✓ ヒアリングOK
→ 条件ヒアリングへ
✗ それも不要
→ 連絡先確認して終了
↓
条件ヒアリング ①〜④希望条件・家族構成・購入理由のヒアリング
「お問い合わせいただきました物件の他にも、お客様にぴったりの物件をご紹介したいので、いくつか基本的なご条件だけお伺いしてもよろしいでしょうか？」
①問い合わせ物件の確認「○○（物件名）のどんなところがお気に入りでしたか？」
②希望エリア「富山市は広いので、大体で良いのですがご希望エリアを教えていただけますか？」
③家族構成「どのくらいの大きさのものをご紹介するかを検討するのに必要なので、家族構成を教えていただけますか？」
④購入理由「おうちを探しているお客様は現住居に問題を感じている方が多いのですが、参考までに購入理由を教えていただけますか？」
⚠️ 嫌がる場合はさらっと流して次へ

「他にも似た物件はありますか？」→ 「業者専用のレインズというサイトに非公開物件も多数ございます。ご来店いただければ一緒に探せます。」
「住所だけ教えてほしい」→ 「申し訳ございません。お応えいたしかねます。担当から改めてご連絡させていただきます。」
「資料だけ送ってほしい」→ 「かしこまりました。メールと郵送どちらがよろしいでしょうか？」→ 資料送付後に追電話
賃貸中の物件→ 「こちらはオーナーチェンジ物件といって投資家向けの物件です。住宅ローンはご利用いただけず、室内見学もできません。」
専門的な質問全般→ 「私では分かりかねますので、担当よりご連絡させていただきます。」
